## 📌 Описание

**XyqwHub** — это универсальный скрипт-хаб для Roblox, который объединяет десятки популярных скриптов в одном интерфейсе.

### ✨ Особенности

| Функция | Описание |
|---------|----------|
| 🌍 Два языка | Английский и русский с переключением на лету |
| 📌 Док-кнопка | Всегда доступна, не теряется среди окон |
| 🎯 34+ скрипта | От аимботов до тpоллинга |
| 🖱️ Перетаскивание | Окно и кнопку можно двигать |
| 🛡️ Анти-спам | Защита от случайных нажатий |
| 🎨 Приветствие | Соцсети и версия при запуске |

### 📦 Скрипты

- **Blade Ball** — взлом для популярной игры
- **AntiKillParts** — защита от смертельных частей
- **Infinite Yield** — админ-панель
- **Walk on walls** — ходьба по стенам
- **AetherX** — мульти-скрипт (устаревший)
- **Doors V2 (Copy)** — копирует скрипт в буфер
- и 30+ других...
