## 🚀 Описание

**XyqwHub** — это универсальный скрипт-хаб для Roblox, который объединяет десятки популярных скриптов в одном интерфейсе с поддержкой двух языков.

---

## ✨ Особенности

| Функция | Описание |
|---------|----------|
| 🌍 Два языка | Английский и русский с переключением на лету (кнопка EN/RU) |
| 📌 Док-кнопка | Всегда доступна, не теряется среди окон |
| 🎯 34+ скрипта | От аимботов до троллинга |
| 🖱️ Перетаскивание | Окно и док-кнопку можно двигать |
| 🛡️ Анти-спам | Защита от случайных нажатий |
| 🎨 Приветствие | Соцсети и версия при запуске |
